# Dodai Tech

[Website](https://dodaitech.dev) · [GitHub](https://github.com/Dodai-Tech) · [dodaidev@gmail.com](mailto:dodaidev@gmail.com)

</div>

Dodai (土台) is the Japanese word for a foundation. We're a small studio that
cares about the layer underneath: the design system, the tools and the shared
pieces that apps get built on.

What we work on:

- Design systems
- Mobile apps
- Wear OS and Garmin apps and watch faces
- Linux desktop environment development
- TUIs, GUIs and developer tooling

We mostly write Rust. The idea is to design something once and then build it
natively for each platform, so a phone app, a terminal tool, a desktop panel and
a watch face still look like they belong together.

## Projects

### dodai-ui
The design system. Four designs (Dodai, Cyberpunk, Material 3 and
Neo-Brutalism), each with a light and dark theme and several accent color
palettes, and components for gpui, iced, egui, Slint, Bevy and the web.

[GitHub](https://github.com/Dodai-Tech/dodai-ui) ·
[Live showcase](https://dodaitech.dev/design-system/showcase/) ·
[Website](https://dodaitech.dev/design-system/)

### dodaitech-website
The source of our website. A Rust generator that builds static pages with
dodai-ui and deploys them to Cloudflare.

## How we work

Our apps have no accounts, no ads and no tracking. The code is open source where
we can make it so, and some apps and watch faces are commercial products.

If you have a question or an idea, email us or open an issue on any repo.
